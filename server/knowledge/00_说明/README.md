# SRT27 知识库（KB）

本目录存放 SRT27 故障诊断智能体的通用信息收集提示。后端启动时扫描 `server/knowledge/` 下的 `.md` 文件（跳过 `00_说明/`），按章节切块，并加载 `知识库/整理后的知识库/农用拖拉机知识库/entries.jsonl` 中的归档条目，共建立 208 个片段的关键词索引（9 个信息收集片段 + 199 个拖拉机及配套系统条目）。用户提问时，RAG 模块检索片段供 LLM system prompt 或本地知识库回复使用。通用内容没有原厂证据，只用于补充机型、工况和伴随现象，不能作为故障原因、维修步骤、参数或周期依据。

## 目录约定

| 目录 | 用途 |
| --- | --- |
| `00_说明/` | 本说明与元信息 |
| `01_通用原理/` | 发动机、冷却、润滑、液压、电气、传动、制动、转向等通用机械原理 |
| `02_农机类型/` | 拖拉机、联合收割机、插秧机、植保机等类型级知识 |
| `03_新能源农机/` | 电动、混动、氢燃料农机 |
| `04_智能农机/` | 无人农机、自动驾驶、远程运维 |
| `05_故障代码/` | DTC / 故障码表与含义 |
| `06_品牌资料/` | 东方红、雷沃、中联、久保田、约翰迪尔等品牌通用资料 |
| `07_具体型号/` | 具体机型（如 MF-25D、DF-1204 等）专属维修手册内容 |
| `99_待整理/` | 临时放置、待归类的原始材料 |

## 文件格式约定

通用 `.md` 文件用二级标题（`##`）分隔信息收集主题，例如：

```markdown
# 发动机水温过高
## 发动机水温过高
请描述已有报警和发生工况。
## 发动机启动困难
请区分启动机不转、转动无力与转动但不着火。
...
```

后端会按 `##` 切块，每块作为一个候选信息收集片段。维修事实按下方归档流程维护来源、完整机型和证据页，不直接粘贴到没有适用元数据的通用文件中。

## 扩展

归档拖拉机知识无需复制到本目录：维护 `entries.jsonl` 的条目编号、品牌、型号、来源编号、原文定位及 `knowledge_path`，后端按编号加载文档中的确切章节，并保留来源和适用范围。农机类型、品牌、型号以及问题中的可辨认品牌／型号参与过滤；匹配结果仍需核实市场、排放、配置和版本。

归档 README、待补资料和原始 HTML/PDF 不自动作为知识加载。修改索引或文档后重启服务，并使用 `npm test` 验证；新增未核对资料不能伪造原文定位或适用范围。

未来如需自动解析 PDF / Word / Excel / TXT，在 `server/knowledge/retriever.ts` 之上增加解析层。

归档条目的固定流程、字段及验收检查见[知识库整理规范](../../../知识库/条目整理规范.md)。`entry_type`区分事实、安全、系统与资料信息；精确型号列表和已明确排放阶段参与匹配，资料索引/核验/缺口不显示为维修判断。
