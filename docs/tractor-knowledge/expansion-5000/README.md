# 拖拉机通识进阶 5000 条

本批新增 **250个细分主题 × 每主题20条 = 5000条学习条目**，编号 `TK-1001`—`TK-6000`，分为50份正文。与[原1000条](../README.md)合计6000条；[总入口](../overview.md)列出两个批次。

## 用途与核验状态

本批是模型辅助编写的工程通识学习资料。初稿与技术审校分开执行：4900条由另一配置模型辅助审校，剩余100条因外部额度限制由当前Codex逐条阅读审阅；随后进行本地重复候选、结构、编号、定位与文件摘要检查，以及Codex选项审阅。审校针对定义、因果、结构条件与危险操作表述，不构成逐条原厂核验、专家审签或实车验证；模型之间达成一致也不是独立实物证据。

正文只维护在本目录50份Markdown中，`index.jsonl`仅保存定位和用途元数据。每条保留 `diagnostic_evidence=false`，不进入机型维修RAG，不改变4853条既有归档。学习条目数量不等于独立故障数量；主题间允许必要的关联，不把近似检测或模型审校当作全量历史语义去重结论。

本批没有专用机型参数和故障码的原厂证据。实际维修需按[既有整理规范](../../../知识库/条目整理规范.md)取得匹配型号、版次及配置的原文，核对证据后另行接入正式来源、索引和分层导航，不能直接删除学习用途标记。
