## 检查与接入

从仓库根目录执行：

```bash
python3 知识库/工具/校验索引.py
npm test
npm run build:server
npm run dev
```

修改索引后重新加载服务，检查`GET /api/health`中的`archivedEntries`是否等于JSONL条数；当前为199条，加9个通用片段共208个片段。再按已记录的品牌/完整型号提问，确认回答保留条目编号、原文页、版本与适用限制。未知机型、排放不匹配或缺少证据时说明资料不足。

原件完整取得、选页核对、GitHub保存和网站部署分别验收。未取得正文的候选及尚未核对的目录不能用于生成操作或诊断参数。
