# 新资料整理模板

复制后替换所有占位符；本模板不加入`sources.json`或`entries.jsonl`，不参与检索。

## 国内使用证据与型号候选模板

先按[整理规范](../条目整理规范.md)核对统计/报道正文，维护[采集优先级](../整理后的知识库/农用拖拉机知识库/采集优先级/README.md)的`证据索引.json`和`型号清单.jsonl`。此阶段是手册采集研究，不写维修条目；以下对象是字段示例，按实际证据填写，未知项保留`null`或明确“未披露”。不要为了填模板编造数量、配置或完整型号。

`证据索引.json`中的来源对象示例：

```json
{
  "source_id": "REPORT-PUBLISHER-DATE-TOPIC",
  "title": "实际正文标题",
  "url": "https://example.com/实际公开入口",
  "publisher": "实际发布方",
  "author": "实际署名或未披露",
  "authority": "official_primary/official_reprint/third_party",
  "publication_date": "实际发布日期",
  "observation_period": "数据观测期；不是网页发布年",
  "fetched_date": "实际取得日期",
  "scope": "地域及覆盖范围；未知项明示",
  "statistic_definition": "统计对象、单位、状态和去重方法；未披露项明示",
  "html_sha256": "实际HTML响应的64位SHA256；未取得正文则省略",
  "html_bytes": null,
  "verified_content": "实际阅读正文/选图范围及未取得原始公示等限制",
  "limitations": ["保有量、购机公示、第三方销量、热度或局部应用分别陈述"]
}
```

每条型号关联证据示例；`reported_units`只存原文明确的该型号台数，热度与品牌总量另列，不填入此字段：

```json
{
  "record_id": "MODEL-REPORT-MODEL",
  "source_id": "REPORT-PUBLISHER-DATE-TOPIC",
  "brand": "原文品牌",
  "model": "报告所列型号；可能缺后缀",
  "evidence_type": "明确证据类型",
  "observation_period": "实际观测期",
  "reported_scope": "实际地域覆盖与未知项",
  "reported_units": null,
  "original_summary": "原创概述，区分原文表述与整理边界",
  "manual_priority": "说明采集理由，不当作使用量排名",
  "limitations": ["完整后缀、排放、配置尚未确认；不从相似产品补造"]
}
```

`型号清单.jsonl`的候选每行一个对象，关联上面的证据记录，单独记录手册搜索入口、取得状态和下一步。候选目录、产品页、视频、培训及失败请求不能计为已取得匹配整机手册；未知的手册编号、版次、PDF页数和哈希不填造。人读README写明统计口径、候选去重数量及未取得资料，不称全国保有量榜。

原始网页响应哈希、本地原创来源记录哈希和手册PDF哈希分别命名；未留全文的外部网页仅保存入口、取得数据及原创概述，不能把`/tmp`文件路径留作GitHub长期链接。官方转载保留原作者，第三方统计不升级为官方原始统计。购机研究仅留必要汇总，不归档个人受益者信息。

取得精确适用的手册并完成封面/正文型号、后缀、市场/排放、配置、版次及证据选页核验后，才使用以下维修资料模板并接入索引。

## 来源对象模板

```json
{
  "source_id": "SRC-BRAND-MODEL-VERSION",
  "brand": "明确品牌",
  "model": "文字型号范围",
  "models": ["原件明确的型号"],
  "title": "原件标题",
  "path": "知识库/原始农机说明书/品牌/型号/原件或来源记录.md",
  "url": "https://example.com/公开来源入口",
  "document_type": "整机说明书/培训/配套系统等",
  "role": "资料用途",
  "version": "编号和实际纸面版本；未知写待核实",
  "version_date": null,
  "pdf_metadata_date": null,
  "scope_boundary": "明确市场/排放/配置与未解决限制",
  "status": "实际取得与指定内容核对状态",
  "sha256": "替换为本地path文件的64位SHA256",
  "bytes": 0,
  "verified_pdf_pages": {"1": "实际核对内容"}
}
```

原件PDF另填`pdf_pages`。仅存来源记录时填`storage_type: link_and_source_record`及实际取得PDF的`manual_sha256/manual_bytes/manual_pdf_pages`，不要混用两组哈希/字节数。明确排放才填`emission_stage`。

## 人读知识卡模板

```markdown
# 品牌／机型／版本

## 来源与适用范围

- 来源编号：SRC-BRAND-MODEL-VERSION
- 原件或来源记录：[链接](相对路径)
- 公开原网址：完整URL
- 版本/市场/排放/配置：实际核验结果
- 已审范围：仅选页或全书；未完成事项
- 冲突：保留原字段与待核实内容

## KB-BRAND-MODEL-001｜清楚的问题标题

- 经核对的事实与完整前提。
- 如何区分现象；哪些只是候选原因。

适用限制：本条自己的边界；不跨用的配置和版本。
整理边界：若为整理者补充则明确标注。
- 证据：来源编号；章节/表号；PDF第N页／印刷第M页。
```

## 机器条目模板

```json
{
  "entry_id": "KB-BRAND-MODEL-001",
  "source_id": "SRC-BRAND-MODEL-VERSION",
  "brand": "明确品牌",
  "model": "明确范围",
  "title": "与Markdown标题完全一致",
  "knowledge_path": "知识库/整理后的知识库/农用拖拉机知识库/机型知识卡/文件.md",
  "locator": "章节/表号；PDF第N页／印刷第M页",
  "entry_type": "维护/故障知识",
  "status": "实际核对程度和未完成验证",
  "scope_boundary": "该条目独有的条件与限制"
}
```

压成一个JSON对象一行后追加JSONL；正文只维护在知识卡。更新目录、来源和采集记录，运行校验和检索测试，再保存GitHub。

条目仅适用于来源中部分配置型号时，另加`models`数组，填原文支持的精确型号子集。检索按该子集筛选并要求用户提供精确型号；不要为凑齐模板填造后缀或等价型号。普通全范围条目可省略该字段。

原件明确时，来源或条目另加`configuration: "CAB"`或`"ROPS"`，检索排除问题中明确的相反配置。混合整册不统一填写；条目不得与来源已定配置冲突。其他配置限制仍在正文和`scope_boundary`保留。

仅适用于明确驱动配置时可加`drive_configuration: "2WD"`或`"4WD"`，同样保留原文证据并排除明确冲突；同时涵盖两驱和四驱的整册不统一填写。
