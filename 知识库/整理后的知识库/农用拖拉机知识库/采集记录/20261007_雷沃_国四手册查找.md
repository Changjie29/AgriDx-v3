## 二、为什么判断「本轮公开网络无可取得正文」

1. 雷沃中文官网（lovol.com / lovol.com.cn）当前仅提供产品参数页与在线留言，未见「服务支持/资料下载」整机说明书栏目；其官方手册分发渠道指向「智农雷沃 APP」与经销商/服务站（官网新闻自述配件查询、保养提醒在 APP 内），不在开放网页提供整机册 PDF。
2. 农机通雷沃官方店铺（nongjitong.com/company/lovol/）的培训/维修保养栏目经本轮重试均 HTTP 200，内容仍只有 2018 年四份交机培训 PDF 与网页文章/视频，无近期国四整机册。
3. 雷沃全球/海外站（lovolglobal、lovol.au/.fr/.ph 等）为出口市场，文档为通用 Technical Bulletin、海外机型博客与视频教程，非中文国四 M/P/MG 平台整机使用保养说明书；出口市场手册不自动证明国内国四适用。
4. 手册聚合站（ManualsLib、truckmanualshub）所列雷沃资料以老平台（TA/TD/TE/TB）、发动机手册、技术规格、零件目录为主，且反爬/付费门槛，未出现 M1204-4X/5X、P1204-4P/4M、M2004、MW2104 等近期国四整机使用保养说明书。
5. 政府鉴定/补贴平台（202.127.42.49、td.sxwhkj）仅提供推广鉴定检测报告与投档参数，不是使用/保养手册；按 rubric 不计。
