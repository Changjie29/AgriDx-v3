## 后续新增固定流程

1. 优先实际官方统计/购机公示，再核可信报道正文与附件。HTTP200、搜索摘要、宣传、鉴定和准入目录不作使用量依据。
2. 记录发布与观察时间、地域、对象、单位、有效公示状态、截点、去重和未知项；购机量、保有量、热度、展示及试用分别表述，只在同口径范围比较。
3. 公示按数量列、有效状态汇总并处理撤销/更正/跨批重复，不按行数代台数；长期档案不保存个人受益者姓名、身份证、电话、具体住址。
4. 按原报告名称建立证据引用，未知后缀不补造，近似机型不合并。国内在用进口品牌也可查，不以企业所在地推购机地域。
5. 查厂家/可信经销商精确整机使用保养手册，核封面、型号后缀、市场/排放、发动机、变速、配置、序列号和版次；目录/产品页/培训/视频/单机发动机册不替代完整整机原件。
6. 真正取得原件后核完整性，扫描及参数表目视审校相关页。稳定编号对应人读知识卡与机器维修索引，完成校验、测试、实际问答及GitHub版本日志。
