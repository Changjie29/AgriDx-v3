## 后续新增固定流程

1. 优先采集农业农村部、省厅、县市购机公示/使用统计；再补可信媒体的可追溯报道。先检查真实正文/附件，不将搜索摘要或HTTP200当证据。
2. 每份记录发布与观察时间、地域、数量单位、统计对象、来源层级、公示状态、截点及去重方法；未知明确留空。补贴购机量≠在用保有量，投档目录/鉴定/推广≠实际使用量，网络热度≠销量。地方应用只证明当地实例。
3. 真实购机公示按数量列和有效状态汇总，去除撤销、重复、更正及跨批重复，避免按行数误计；长期档案不保存个人购机受益者姓名、身份证、电话等信息。只在相同地域/时间/口径下比较。
4. 为证据明确的型号建立候选引用，保留原报告写法；完整后缀和排放未知不补造。跨地区证据和最新资料用于调整研究队列，不凭品牌印象给全国排名。
5. 从厂家与可信经销商查确切整机使用/保养手册；读封面、编号、版本、市场、排放、序列号、发动机、变速及配置。旧版/培训/产品页/单机发动机手册不代替新整机原件。失败与候选继续留在研究档案。
6. 原件取得并核验完整性后审读相关正文，扫描与参数表须目视核对。以稳定编号写人读知识卡，再将同编号与适用边界加入维修索引，执行归档/检索/实际问答验收及GitHub版本日志。
