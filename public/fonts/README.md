# 网站字体

字体来自 Fontsource 5.3.0：`@fontsource-variable/inter`、`@fontsource-variable/noto-sans-sc` 与 `@fontsource-variable/noto-serif-sc`。保留各字体的 SIL Open Font License 于对应目录的 LICENSE。

`app/local-fonts.css` 声明 normal 可变字重与 unicode-range；浏览器按字符加载 WOFF2 切片，字体由本站提供。Inter 保留 latin / latin-ext，中文字体保留完整切片。更新字库时同步替换文件与 CSS 声明。
